## 🎨 Penerapan Prinsip UI/UX
Website ini dibangun dengan memperhatikan ketentuan tugas, antara lain:
1. **Konsistensi Desain:** Menggunakan skema warna yang konsisten (*Deep Navy Blue* untuk kesan profesional dan *Soft Blue* sebagai aksen), serta tipografi menggunakan font *Poppins*.
2. **Navigasi yang Jelas:** Terdapat *Sticky Navbar* di bagian atas halaman untuk memudahkan perpindahan ke section Tentang Saya, Pendidikan, Pengalaman, dan Kontak.
3. **Tata Letak Rapi:** Menggunakan sistem tata letak modern (CSS Grid dan Flexbox) untuk menyusun portofolio pendidikan dan komponen garis waktu (*timeline*) pengalaman.
4. **Responsif (Mobile Friendly):** Dilengkapi dengan *Media Queries* sehingga tampilan otomatis menyesuaikan diri saat diakses melalui smartphone, tablet, maupun laptop (Asus).
